# 早押しクイズロワイヤル

それぞれのスマホから同じ部屋に入って、早押しクイズで対戦するゲームです。
ブラウザで開くだけで遊べます（アプリのインストールは不要）。

## 遊び方

### ランクマッチ（全国のだれかと対戦）

はじめの画面の「2人対戦」「4人対戦」を押すと、レートの近い相手をさがして対戦します。登録は要りません（端末ごとにプレイヤーが自動でつくられます）。

- **2人対戦**: 先に5問正解した方の勝ち。ライフは3つで、まちがえる（時間切れも）と1つ減り、なくなると負け（最大15問）
- **4人対戦**: 全10問。だれかが押すと問題文が止まり、3秒のあいだ、ほかの人も押せる（3人まで）。押した人はそれぞれ自分の選択肢で答え、正解すると押した順に3点・2点・1点。ライフ3つ、なくなると脱落
- レートは1500から始まり（5級）、勝つと上がり負けると下がる。10級〜九段、2200以上は名人
- ジャンル・出題・答え方は選べない（すべてのジャンル・まぜる・ミックス）
- 名前は、ふさわしくないことばを含むと使えない。対戦結果やランキングから通報・ブロックできる

### 友だちと遊ぶ

1. 1人が「部屋をつくる」を押し、表示された4けたの部屋番号をみんなに伝える
2. ほかの人は「部屋に入る」から部屋番号を入れて参加（招待リンクからでもOK）
3. ホストがスタート。問題文が1文字ずつ出るので、わかったら早押しボタン
4. 一番早く押した人だけが答えられる。正解で1点、まちがえるとその問題はもう押せない（お手つき）

答え方は部屋ごとに選べます。

- **選択肢** … 4つの選択肢から選ぶ
- **文字入力** … 答えの1文字ごとに、正しい文字1つとまぎらわしい文字3つが出るので、順に選んで答えを作る（答えがひらがな・カタカナの問題だけ）
- **ミックス** … 選択肢の問題に、文字入力の問題が3割ほどまざる

ホストは待合室で、出題するジャンル（15種類・複数選べる）も選べます。

出題は「文章」「画像」「まぜる」から選べます。画像クイズは、写真の一部を大きく拡大したところから少しずつ引いていき、何が写っているかを当てます（まぜると2割ほどが画像クイズ）。

パソコンでは スペースキーで早押し、1〜4キーで選択肢（文字入力のときは文字）を選べます。

## しくみ

- `public/` … スマホに表示する画面（HTML / CSS / JavaScript）
- `src/worker.js` … 対戦サーバーの入口。Cloudflare Workers で動く
- `src/room.js` … 部屋（1つの部屋 = 1つの Durable Object）。早押しの判定はすべてサーバー側で行う
- `src/ladder.js` … ランクマッチの受付（全体で1つの Durable Object）。相手さがし・レート・ランキング・通報。記録は SQLite に保存
- `src/rating.js` … レートの計算と段級位 / `src/names.js` … 名前のチェック
- `quiz/` … 問題を作るしくみ。`quiz/data/` の表から問題を作り、`src/questions.generated.json` に書き出す
- `questions.js` … 手で書いた問題（必ず使われる）
- 問題はサーバー側だけで読むので、答えがスマホに漏れない

## 手元で動かす

```
npm install
npm run dev
```

`http://localhost:8787` をブラウザで開きます。同じWi-Fiのスマホからは `http://<パソコンのIPアドレス>:8787` で開けます。

Windows の PowerShell で `npm` がエラーになるときは、`npm.cmd run dev` のように `npm.cmd` を使ってください。

## テスト

`npm run dev` を動かしたまま、別のターミナルで実行します。

```
npm test          # サーバーのテスト（偽プレイヤーを WebSocket でつないで、1ゲーム通して確かめる）
npm run test:ui   # 画面のテスト（ヘッドレス Chrome で2〜4人分のページを開いて操作する）
```

- `test/play-test.cjs` … 早押し・回答・得点・結果 / `test/input-test.cjs` … 文字入力 / `test/genre-test.cjs` … ジャンル選び / `test/image-test.cjs` … 画像クイズ / `test/ranked-test.cjs` … ランクマッチ
- `test/ranked-smoke.cjs` … 公開したあと、本番のランクマッチを確かめる（`WS_URL=wss://<公開先>/ws` を付けて実行。テスト用の記録は最後に消える）
- 画面のテストのスクリーンショットは、一時フォルダの `hayaoshi-ui-test` に保存されます

## 公開する（Cloudflare）

```
npx wrangler login
npm run deploy
```

表示された `https://hayaoshi-quiz-royale.<アカウント名>.workers.dev` を開けば、どこからでも対戦できます。
Workers の無料プランで動きます。30分操作のない部屋は自動で閉じます。

## Android アプリ（Google Play）

`android/` は、公開したサイトを全画面で表示する Android アプリ（TWA）のプロジェクトです。
ゲームの中身はサイト側にあるので、`npm run deploy` で公開し直せばアプリにも反映されます（アプリの作り直しは不要）。

ビルドは `android\build.cmd` を実行します（Android Studio が入っていること）。

- `android/app-release-bundle.aab` … Google Play Console にアップロードするファイル
- `android/app-release-signed.apk` … テスト用のスマホに直接入れるファイル

署名用の鍵は `%USERPROFILE%\hayaoshi-android-key\`（`upload.jks` と `password.txt`）にあります。GitHub には上げず、別の場所にもバックアップしておいてください。

Google Play でアプリ署名を有効にしたら、Play Console に表示される「アプリ署名鍵の証明書」の SHA-256 を `public/.well-known/assetlinks.json` に追加して公開し直してください。これがないと、ストアから入れたアプリの上部に URL バーが出ます。

## 問題を追加する

問題は15ジャンル × 667問 ＝ 約1万問です。

- 手で書く問題は `questions.js` に1行ずつ追加します。

  ```js
  { q: '問題文', answer: '正解', wrong: ['まちがい1', 'まちがい2', 'まちがい3'], genre: '雑学' },
  ```

- たくさん作る問題は `quiz/data/` のファイルに、表（`名前|説明` の行）や `[問題, 正解, [まちがい3つ]]` の形で書きます。表から作る問題は、同じ表のほかの行がまちがいの選択肢になります。

書いたら `npm run quiz` で作り直します（`npm run dev` と `npm run deploy` の前にも自動で動きます）。
選択肢の数・重複・長さなどを確かめ、ジャンルごとの数が足りないとエラーで止まります。

「次のうち〜は？」や「〜に入っていないのは？」のように、選択肢を見ないと答えが決まらない問題は、文字入力では出しません（`src/kana.js`）。

「〜ですが、」のように、最後まで聞かないと答えが決まらない問題にすると盛り上がります。

## 画像クイズを追加する

画像は Wikimedia Commons で CC0（パブリックドメイン）として公開されている写真だけを使います。

1. `quiz/images/subjects.js` に `[正解, 種類, 英語の検索語]` を追加する
2. `node quiz/images/search.js 正解` で候補を検索する（`quiz/images/cache/sheets/` に候補の一覧画像ができる）
3. 使う写真と、最初に拡大する場所を `quiz/images/picks.js` に書く
4. `npm run images` で、拡大から全体までの7段階の画像（`public/q/`）・`src/images.generated.json`・出典ページ（`public/credits.html`）を作り直す

画像のファイル名は答えがわからない名前にしてあり、スマホには今の段階と次の段階の画像しか送らないので、先に全体を見ることはできません。

## Google Play のストア素材

`store/` に、掲載文（`listing.md`）、Play Console の入力内容の下書き（`play-console.md`）、アイコン・フィーチャーグラフィック・スクリーンショットがあります。

スクリーンショットは `npm run store:shots`（`npm run dev` を動かしたまま）で `store/raw/` に撮り、`npm run store:images` で見出しを付けて `store/screenshots/` に書き出します。見出しの文は `store/tools/compose.cjs` にあります。

## 設定を変える

文字が出る速さ・制限時間・最大人数などは `src/room.js` の先頭に、ランクマッチの相手さがしと通報の設定は `src/ladder.js` の先頭に、レートの計算は `src/rating.js` にまとめてあります。
