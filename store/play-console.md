# Play Console の入力メモ

「ポリシーとプログラム」→「アプリのコンテンツ」で聞かれることへの答えの下書きです。
画面の文言は変わることがあるので、迷ったら下の「事実」に合わせて答えてください。

## アプリの事実（答えのもと）

- 登録・ログインはない。名前（ニックネーム、10文字まで）を入れれば遊べる
- 友だちと遊ぶ部屋の名前と得点は、部屋が閉じると消える（サーバーのメモリだけ）
- ランクマッチで遊ぶと、プレイヤー番号（端末ごとに自動でつくる）・名前・レート・対戦数・勝った数をサーバーに保存する
- 通報すると「だれがどの名前を通報したか」を保存する。3人から通報された名前は使えなくなる
- 対戦の組み合わせの記録は、結果を計算したらすぐ消す（結果が届かなかったものも1時間で消す）
- ランクマッチの記録は「ランキングを見る」→「ランクマッチの記録を消す」で、いつでも本人が消せる
- 広告なし、解析ツールなし、課金なし、位置情報・連絡先・メールアドレスは集めない
- 通信は HTTPS / WSS（暗号化あり）。サーバーは Cloudflare（サービス提供者）
- Android アプリは TWA（中身はウェブ版と同じ）。広告 ID は使わない（ライブラリは androidbrowserhelper だけ）
- チャットはない。ほかの人に見えるのは名前と成績だけ
- 部屋をつくってスタートすれば、1人でも遊べる（審査の人も1人で試せる）

## データ セーフティ

### データの収集とセキュリティ

| 質問 | 答え |
| --- | --- |
| 必須のユーザーデータを収集または共有するか | はい |
| 収集するデータは転送時に暗号化されるか | はい |
| アカウントの作成方法 | 「アプリでアカウントを作成できない」（登録・ログインがないため） |
| データの削除をリクエストする方法（URL） | `https://hayaoshi-quiz-royale.qoj.workers.dev/privacy#delete` |

プレイヤー番号を「アカウント」とみなすべきか迷う場合は、アカウントの作成方法で「その他」を選んでください。
アカウント削除の URL にも、上と同じ `privacy#delete` を入れられます（消し方と、消える情報が書いてあるページ）。

### 収集するデータの種類

「共有」はすべて「いいえ」です（Cloudflare はサービス提供者なので、共有にはあたりません）。

| データの種類 | 中身 | 一時的な処理だけか | 必須か任意か | 目的 |
| --- | --- | --- | --- | --- |
| 個人情報 → 名前（Name） | ニックネーム | いいえ（ランクマッチで保存） | 必須 | アプリの機能 |
| アプリのアクティビティ → その他の操作（Other actions） | 早押し・回答、レート・対戦数・勝った数、通報 | いいえ | 必須 | アプリの機能、不正行為の防止・セキュリティ・コンプライアンス |
| デバイスまたはその他の ID（Device or other IDs） | ランクマッチのプレイヤー番号 | いいえ | 任意（ランクマッチのときだけ） | アプリの機能 |

ほかの項目（位置情報・連絡先・メールアドレス・写真・音声・ファイル・カレンダー・健康・金融・ウェブ閲覧履歴・アプリの操作・クラッシュログなど）は、すべて「収集しない」です。

## コンテンツのレーティング

カテゴリは「ゲーム」。質問には事実どおりに答えます。

| 内容 | 答え | 補足 |
| --- | --- | --- |
| 暴力・流血・恐怖 | いいえ | 歴史問題に戦いの名前が出るだけで、描写はない |
| 性的な内容・ヌード | いいえ | |
| 下品なことば・ユーモア | いいえ | 名前は NG ワードで制限している |

| ユーザーどうしのやりとり | はい | ランクマッチで知らない人と対戦し、名前が見える。チャットはない。NG ワード・通報・ブロックあり |
| 位置情報の共有 | いいえ | |
| デジタル商品の購入 | いいえ | |
| 制限のないインターネットアクセス（ブラウザ機能） | いいえ | |

## ターゲット ユーザー

「13〜15歳」「16〜17歳」「18歳以上」を選びます。

ランクマッチでは知らない人と対戦するので、13歳未満を含めると「ファミリー」ポリシーの追加の要件がかかります。
「子どもの興味をひく可能性」は「いいえ」でよいと考えます（子ども向けのキャラクターや絵を使っていないため）。

## 公開までの流れ

1. 「クローズド テスト」のトラックをつくり、テスターを12人以上登録する
2. `android/app-release-bundle.aab` をアップロードして、テスターに配る
3. 12人がテストに参加したまま14日たったら、「製品版へのアクセス」を申請する
4. 「アプリの署名」に出る**アプリ署名鍵の証明書の SHA-256** を教えてください。`public/.well-known/assetlinks.json` に入れて公開しなおすと、アプリの上部にブラウザの URL バーが出なくなります
