# Google Play ストア掲載情報（貼りつけ用）

Play Console の「ストアでの表示」→「メインのストア掲載情報」に、そのまま貼りつけられる文です。

## アプリ名（30文字まで）

```
早押しクイズロワイヤル
```

## 簡単な説明（80文字まで）

```
1万問の早押しクイズで、友だちや全国のだれかとスマホで対戦！画像クイズ・ランクマッチも
```

## 詳しい説明（4000文字まで）

```
スマホ1台に1人。みんなで同じ問題を見て、わかった人から早押しで答える対戦クイズです。
友だちと部屋をつくって遊ぶことも、ランクマッチで全国のだれかと腕をきそうこともできます。

■ 早押しのルール
問題文は1文字ずつ出てきます。答えがわかったら「早押し！」。
いちばん早く押した人だけが答えられます。まちがえるとお手つきで、その問題はもう押せません。

■ 1万問・15ジャンル
ことば・文学／歴史／地理／社会／理数系／からだ・健康／生き物・自然／乗り物・テクノロジー／芸術・伝統文化／エンタメ／スポーツ／遊び・趣味／食べ物・飲み物／暮らし／雑学
どのジャンルも667問ずつ、あわせて10,005問。

■ 答え方は2種類
・選択肢：4つの中から選ぶ
・文字入力：4つの文字から、答えを1文字ずつ選んでいく
2つをまぜて出す「ミックス」もあります。

■ 画像クイズ
大きく拡大された写真が、だんだん引いていきます。「これは何？」とわかったら早押し！
動物・食べ物・乗り物・楽器・道具・名所・スポーツから130問。

■ ランクマッチ
・2人対戦：先に5問正解した方の勝ち。ライフは3つで、まちがえると1つ減り、なくなると負け
・4人対戦：1問に3人まで答えられ、早く押した順に3点・2点・1点。ライフは3つで、なくなると脱落。全10問
勝てばレートが上がり、10級から九段、そして名人へ。上位50人はランキングにのります（3戦以上）。

■ 友だちと遊ぶ
部屋をつくって、4けたの部屋番号かリンクを送るだけ。最大8人まで遊べます。
問題数（5・10・20問）、出題（文章・画像・まぜる）、答え方、ジャンルを選べます。部屋をつくれば1人で練習することもできます。

■ ブラウザからも参加できる
アプリを入れていない友だちも、スマホやパソコンのブラウザから同じ部屋に入れます。

■ 安心して遊べるように
・アカウント登録なし、広告なし
・ランクマッチでは、ふさわしくない名前は使えません。通報・ブロックもできます
・ランクマッチの記録は、アプリからいつでも消せます

※ 遊ぶにはインターネット接続が必要です。
※ 画像クイズの写真は、Wikimedia Commons のパブリックドメイン（CC0）の写真を使っています。
```
